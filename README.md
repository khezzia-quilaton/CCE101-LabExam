# Student Grade Calculator

A simple Java program that asks for a student's name and three subject grades, calculates the average, and displays whether the student passed or failed.

### Program Requirements
  Ask for the student's name.
  Accept three subject grades.
  Calculate the average of the three grades.
  Display the student's name, average, and status.
  Display PASSED if the average is 75 or above; otherwise, display FAILED.
